# Streamspace
### Анонминый блог с Ollama-сервисом для генерации постов по недавним ИТ-новостям. Есть админ-панель.
## Запуск:
```
docker-compose up
```
### Использовались:
* Express.js;
* HTML + CSS + JS;
* SQLite;
* Ollama (Deepseek-R1:8b);
* NewsAPI.
### Dependencies
```
docker
docker compose
```
